# ⚡ ANDROID - DÉMARRAGE RAPIDE (5 min)

**La méthode la plus facile et rapide pour avoir l'APK**

---

## 🎯 COPIE/COLLE DIRECTEMENT DANS TON TERMINAL

### Sur Mac/Linux :

```bash
npm install -g eas-cli
eas login
cd trading-app/mobile
npm install
eas build --platform android --profile preview
```

### Sur Windows (cmd.exe) :

```cmd
npm install -g eas-cli
eas login
cd trading-app\mobile
npm install
eas build --platform android --profile preview
```

---

## 📱 Ensuite

1. **Attends 10 minutes** ⏳ (compilation en cours)
2. **Tu reçois un lien** de téléchargement → Clique dessus
3. **Le fichier `.apk` est téléchargé**
4. **Envoie l'APK sur ton téléphone** (email, Telegram, etc.)
5. **Clique sur l'APK** sur ton téléphone
6. **Appuie sur INSTALLER** ✅
